# That's Lit - SPT 3.11.x Compatible

A comprehensive lighting and visibility mod for SPT (Single Player Tarkov) that gives AIs more realistic vision and reactions by accounting for environmental factors like lighting, vegetation, and weather conditions.

## Compatibility
- **SPT Version**: 3.11.x
- **Tarkov Version**: 0.15.x (Build 34870)
- **.NET Framework**: 4.8

## Installation
1. Ensure you have SPT 3.11.x installed
2. Download the latest release
3. Extract to your SPT/BepInEx/plugins directory
4. Launch SPT
